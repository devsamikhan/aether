# AETHER 2.0 Language Support for Visual Studio Code & Cursor

Official Visual Studio Code extension providing rich language intelligence, syntax highlighting, snippets, and diagnostics for the **AETHER 2.0** programming language.

## 🚀 Features

* **Advanced Syntax Highlighting:** Neon grammar coloring for all 260+ tokens, intent contracts, quantum gates, tensors, knowledge graphs, and CRDTs.
* **Intelligent Snippets:** Instant scaffolding for `intent`, `quantum`, `tensor`, `graph`, `live`, `fn`, and `class`.
* **Language Configuration:** Automatic bracket pairing, comment toggling (`#`, `//`, `/* */`), and indentation rules.
* **Language Server Protocol (LSP Lite):** Real-time syntax and invariant validation powered directly by `aether lsp`.

## 📦 Installation

To install this extension locally into your VS Code or Cursor:

1. Copy or symlink this directory into your VS Code extensions folder:
   * **Windows:** `%USERPROFILE%\.vscode\extensions\aether-lang`
   * **macOS / Linux:** `~/.vscode/extensions/aether-lang`

Or run the AETHER toolchain command:
```bash
aether install --vscode
```
