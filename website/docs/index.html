AETHER 2.0 Developer Guide

Welcome to the official documentation and tutorial portal for the AETHER 2.0 programming language. AETHER combines declarative intent contracts, quantum state vector simulation, native deep learning tensors, knowledge graph traversal, and Erlang-grade live code swapping into a single unified systems language.

1. Quickstart & Installation

AETHER ships as a standalone, zero-dependency native executable. No runtimes, no external DLLs, and no administrative privileges required.

Windows (PowerShell)

PowerShell
irm https://raw.githubusercontent.com/devsamikhan/aether/main/install.ps1 | iex

Linux & macOS (Terminal)

Bash
curl -fsSL https://raw.githubusercontent.com/devsamikhan/aether/main/install.sh | bash

2. Toolchain Doctor & CLI

After installation, verify your environment health using the built-in system doctor:

CLI
aether doctor
aether bench
aether new my_project --template ai
cd my_project
aether run src/main.ae

4. Intent-Driven Programming

Intent blocks allow you to bind schema constraints, preconditions, and postconditions to computational state. The runtime mathematically proves these invariants before execution proceeds.

intent_contract.aeRun in Playground ↗
intent SecureVault {
    schema {
        account_id: String;
        balance: Float;
        withdrawal: Float;
    }
    invariants {
        require(balance >= 0.0);
        require(withdrawal > 0.0);
        require(balance >= withdrawal);
        ensure(balance == old(balance) - withdrawal);
    }
}

5. Post-Quantum Algorithmic Simulation

AETHER natively embeds a state vector matrix simulator supporting Hadamard, Pauli-X/Y/Z, CNOT, and phase gates.

quantum_bell.aeRun in Playground ↗
import quantum;

let sim = QuantumSimulator.new(2);
sim.hadamard(0);      // Put Qubit 0 into Superposition (|0⟩ + |1⟩)/√2
sim.cnot(0, 1);        // Entangle Qubit 0 and 1 into Bell State |Φ+⟩

let measurement = sim.measure_all();
print("Measurement result: " + str(measurement));

6. Deep Learning & Autograd

First-class multidimensional tensors with reverse-mode automatic differentiation.

neural_autograd.aeRun in Playground ↗
import tensor;

let w = Tensor.randn([2, 2], requires_grad=True);
let x = Tensor.from_vec([[1.0, 2.0], [3.0, 4.0]]);
let b = Tensor.zeros([2, 2]);

let y = x.matmul(w) + b;
let loss = y.sum();

loss.backward();
print("Weight gradients: " + str(w.grad()));

9. Swarm CRDTs Convergence

Mathematically proven Conflict-Free Replicated Data Types ensuring eventual consistency across distributed nodes without locks.

crdt_swarm.aeRun in Playground ↗
import crdt;

let c1 = GCounter.new("node_1");
let c2 = GCounter.new("node_2");

c1.increment(5);
c2.increment(10);

c1.merge(c2);
print("Converged Total: " + str(c1.read())); // 15
